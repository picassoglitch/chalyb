## 1. HARD RULES (every workstream)

1. **Nothing on `main` changes except WS-1-H (the Mercado Pago hotfix PR).** Everything else stacks on the rebuild branches.
2. **One price source.** Every amount a person sees, every amount sent to Mercado Pago, every amount in an email, consent record, JSON-LD or legal page comes from `src/config/pricing.ts` helpers. 6. **No claim the code can't honor.** A trial, price, badge, tool count, saving, reference price, CFDI or support promise renders only when the flag/config that makes it true is on.

12. **No tickets for Chalyb, ever.** Don't create, update or comment on Linear issues, GitHub issues or any other tracker for Chalyb. Everything lives in documents: PR descriptions, `docs/` files, and the §12 report. Open items go into `docs/prompts/…` or the PR text, never a ticket.

## WS-8 · FIX-S: refund and chargeback policy (REVISION §S, owner-approved 09:53), its own fix · `claude/rebuild-p6h-refunds-chargebacks`

**Non-negotiable rules (each one has a test):**
1. **A dispute alone never suspends an account.** `chargeback_opened` changes nothing: access, plan, price, `loyalty_step`, trial eligibility. Remove any P5 code that restricts on dispute open (the old §10.2(a)); `rg -n "chargeback|dispute|contracargo" src` and list each hit in the PR.

3. **The user always keeps content download** (clips, results, exports), even when restricted or closed. There is no fee, interest or penalty.
4. **A refund or a dispute never resets the Lealtad step** (`loyalty_step` unchanged; Términos §4 bis.5, §7.3, §10.2).
5. Refunds are limited to the legal cases. There is no courtesy refund, and requesting one never harms the user.
